# C Day 107 – Hospital Appointment Management System

## Description
A menu-driven Hospital Appointment Management System developed using C. It manages patient appointments, doctor details, appointment dates and status.

## Features
- Book appointments
- View all appointments
- Search by appointment ID
- Update appointment status
- Cancel appointments
- Save records in a text file

## Technologies Used
- C Programming
- Structures
- Arrays
- Pointers
- Functions
- File Handling

## Files
- `hospital.c` – Main program
- `appointments.txt` – Sample appointment records

## How to Compile and Run

```bash
gcc hospital.c -o hospital
hospital.exe
```

## Concepts Learned
Structures, arrays, pointers, functions, string handling, file handling and record management.
